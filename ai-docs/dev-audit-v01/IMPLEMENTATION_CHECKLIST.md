# План устранения замечаний аудита SMJ

Источник: [REPORT.md](REPORT.md). Статусы обновляются только после проверки соответствующего поведения; `[~]` означает работу, `[ ]` — не закрыто.

Текущее состояние: локальные ошибки результата исправлены, но SMJ остается экспериментальным. `INNER`/`LEFT`/`RIGHT`/`FULL` проходят с реальным spill и build больше лимита памяти. Ограниченный памятью блочный обход повторяющейся группы работает для одноключевых страниц и длинных серий внутри смешанных страниц. При spill probe может обрабатывать опубликованные build-батчи до завершения build. Приёмочный INNER 10M×10M с уникальными ключами прошёл при лимите 16 МиБ и линейном чтении spill; модель стоимости и Iceberg sort-elision остаются открытыми. Штатный `OFF` сохраняется.

## Ограничение памяти и lifecycle

- [~] P0-6 — build больше лимита памяти и отдельная большая группа функционально проходят с реальным spill для `INNER`/`LEFT`/`RIGHT`/`FULL`; блочный повтор для одноключевых и смешанных probe-страниц и потоковое перекрытие build/probe проверены. INNER 10M×10M прошёл с пиком памяти задачи ≤16 МиБ и чтением spill <2× записи. Полная нагрузочная матрица и P0-6c ещё открыты.
- [x] P0-6 safety — учет удержанной памяти при накоплении build переведен с O(число страниц) на O(1) на входную страницу; readback spill-страниц резервирует память и контролируемо отклоняет превышение лимита. Spill-батчи дописываются в один файл, без роста числа открытых файлов и буферов. Порог spill учитывает удержанную память и ограничен четвертью query memory limit. Probe-блок резервируется только при наличии свободного места для крупнейшей build-страницы; тест со страницей около 12 КиБ при лимите 16 КиБ прошел. Одна отдельная страница по-прежнему должна помещаться в memory limit.
- [x] P0-6 lifecycle — резерв build-страниц живет в task memory context до уничтожения bridge; закрытие незавершенного build освобождает его и завершает ожидание probe с ошибкой. Тесты удержания/освобождения памяти и прерывания прошли.
- [x] P0-6 probe index safety — глобальные массивы смещений и отметок `RIGHT/FULL` удалены; адреса residual filter вычисляются без массива, отметки `RIGHT/FULL` ограничены текущей группой и при нехватке памяти записываются в spill-файл с учтенным буфером. Превышение лимита даже для буфера дает `EXCEEDED_LOCAL_MEMORY_LIMIT`; тест с лимитом 1 байт прошел.
- [x] P0-6a — завершённые spill-батчи публикуются через bridge до `build.finish()`; probe блокируется на будущих страницах, сохраняет состояние обнаружения группы, пересекающей несколько батчей, и продолжает после публикации нового батча. Незавершённый batch остаётся под учтённым резервом build, replay имеет отдельный резерв, writer и reader работают с одним файлом и ограниченным снимком уже завершённых страниц. Тесты INNER/FULL проверяют выдачу совпадений до `build.finish()` и ожидание границы группы; отдельный тест проверяет replay зашифрованного префикса при активном append. Без spill probe по-прежнему ждёт завершения build.
- [x] P0-6b — `finish()` не возвращает spill-раны в heap: probe лениво читает один файл, повторно открывая нужный диапазон через ограниченный checkpoint-индекс; residual filter не копирует все страницы. Отметки `RIGHT/FULL` при нехватке памяти переходят в дисковый bitmap. Одноключевые probe-страницы всех четырех типов JOIN собираются в блок до 8 МиБ и не более четверти query memory limit; build-группа обходится один раз на блок, обработка периодически уступает управление. Длинные серии (от 32 строк) внутри смешанной страницы также выделяются в блок, а короткие остаются на построчном пути. `LEFT/FULL` выводят несовпавшие probe-строки после обхода блока. Адрес уже известной build-строки передается residual filter без повторного чтения соседних spill-страниц. Двухстраничный replay-кэш удерживает предыдущую страницу при проверке границы группы, а при нехватке памяти возвращается к одной странице. Добавлен JMX-счетчик сериализованных байтов чтения spill. Тест с 1024 build-страницами и 128 probe-страницами при лимите 16 КиБ проверяет менее 16 000 повторных загрузок страниц и read/write bytes < 16; тест с тремя probe-страницами проверяет менее 800 загрузок вместо исходных 1006 и read/write bytes < 3. Тест смешанной страницы с 128 повторениями проверяет менее 3000 загрузок и read/write bytes < 6. Приёмочный INNER 10M×10M проверяет каждый выходной ключ, пик памяти ≤16 МиБ и read/write bytes < 2; прошёл за 15,14 с внутри теста. Без двухстраничного кэша этот сценарий выявил ~20× amplification.
- [~] P0-6c — глобальные массивы смещений и отметок удалены, адреса residual filter вычисляются на лету. Пройденные страницы освобождаются с уменьшением резерва памяти для replayable spill, запасного spiller и пути без spill; список без spill больше не копируется residual filter. `groupRows` и порядковые номера переведены на `long`; фильтр получает адрес текущей build-строки через одноэлементный список и индекс `0`, дисковый bitmap принимает `long` позиции. Его тест с позициями выше `Integer.MAX_VALUE` прошел. Полный JOIN с группой более 2,1 млрд строк и профили памяти еще не проверены, поэтому пункт остается частично открытым.
- [x] P0-6d — для `RIGHT/FULL` совпадения фиксируются только в текущей группе; закрытая unmatched-группа выводится постранично до следующего ключа и освобождается. Тесты с residual filter, большим промежутком между probe-ключами и реальным spill прошли.
- [~] P0-6e — прошел реальный spill для `INNER`/`LEFT`/`RIGHT`/`FULL`: 1256 build-страниц больше лимита 16 КиБ, редкие probe-ключи, 256 страниц `NULL`-хвоста; отдельная группа в 256 страниц повторно читается, а `RIGHT` с 18 000 строк и residual filter использует дисковый bitmap. Пройдены тесты асинхронного spill, отмены build, concurrent build/probe и блочного повтора с residual filter и unmatched-строками. Приёмочный INNER 10M×10M с пиком памяти ≤16 МиБ прошёл; остаются большие сценарии outer join и профили памяти для других распределений ключей.
- [x] P0-7 — ожидание future, проверка ошибки и блокировка входа реализованы; тесты управляемого успешного и ошибочного spill прошли.
- [x] P1-1 — unmatched RIGHT/FULL build-строки выводятся страницами; тест 80 000 строк прошел.
- [x] P1-2 — фиктивная outer-ссылка убрана; тестовая обвязка больше не регистрирует factory дважды, после закрытия probe factory/operator bridge очищается во всех операторных сценариях.

Потоковый INNER/FULL прошел; остаются нагрузочная приемка P0-6b и профили peak memory.
